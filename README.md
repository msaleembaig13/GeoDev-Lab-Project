# Healthcare Accessibility Mapping in Dera Ghazi Khan Local Government Area, Punjab, Pakistan

This project explores healthcare accessibility across wards in Dera Ghazi Khan Local Government Area, identifying communities located more than 7 km from health facilities using GIS and spatial analysis.

## Project focus:
Identifying wards in Dera Ghazi Khan Local Government Area, Punjab, Pakistan, located more than 7 km from a health facility using GIS, spatial analysis, and Python.

 
 MUHAMMAD SALEEM BAIG

 See project-brief.md for the full brief.

 ## The Question

 Which wards in Dera Ghazi Khan Local Government Area, Punjab, are more than 7 km from a health facility?

### Progress

 -  Week 1, project brief with a source link for every dataset

 - Week 2, data downloaded, opened and described

 - Week 3, reprojected, clipped and quality checked

 - Week 4, first spatial analysis, checked four ways

 - week 5, python setup and environment preparation
